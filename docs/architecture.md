# Архитектура

## Управление окружением
- Базовая версия Python — 3.13.5; совместимость закреплена в `pyproject.toml` через `requires-python = ">=3.13.5,<3.14"`.
- Все обязательные зависимости перечислены в секции `[project.dependencies]`: `selenium` (работа с браузером), `python-dotenv` (загрузка чувствительных параметров из `.env`), `webdriver-manager` (резервная установка chromedriver для старого сценария `app/afip_old.py`). Минимальные версии повышены до `python-dotenv>=1.2.1`, `selenium>=4.38.0`, `webdriver-manager>=4.0.2`, чтобы гарантировать совместимость с Python 3.13.5 и свежими релизами браузеров.
- Инструменты разработки (`ruff`, `black`, `isort`) вынесены в extra `dev`, что упрощает локальное форматирование и проверку стиля без засорения прод зависимостей.

## Структура кода
- Рабочие модули лежат в `app/modules/`; главный класс `AFIP` в `afip.py` инкапсулирует Selenium-поток заполнения форм и повторно используется из ноутбуков.
- Папка `app/notebooks/` предназначена для ручной отладки сценариев согласно правилу, что ноутбуки используют готовые модули, а не содержат уникальную бизнес-логику.
- Файлы `blank.html` и `data.json` служат вспомогательными ресурсами для браузерной автоматизации и хранения локальных данных.

## Контроль качества
- `ruff` проверяет стиль по правилам E/F/I и использует `app` как корневую папку исходников; минимальная версия — `ruff>=0.14.5`.
- `black` (`>=24.10.0`) и `isort` (`>=6.0.1`) настроены на длину строки 120 и совместны по профилю, что обеспечивает детерминированный формат импортов и кода.
